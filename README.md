# Smart Invoice Manager (স্মার্ট ইনভয়েস ও ডিলার ম্যানেজমেন্ট সিস্টেম)

একটি সম্পূর্ণ **Free**, **Open-Source** এবং **Offline-First Android Invoice & Dealer Management Application**। 
এই অ্যাপটিতে কোনো পেইড এপিআই (Paid API), পেইড ডেটাবেজ বা পেইড সার্ভারের প্রয়োজন নেই। সম্পূর্ণ প্রজেক্টটি GitHub-এ আপলোড করে বিনামূল্যে Android Studio অথবা GitHub Actions CI/CD এর মাধ্যমে Android APK/AAB তৈরি করা যায়।

---

## 🌟 প্রধান সুবিধাসমূহ (Key Features)

1. **নিরাপদ অ্যাডমিন লগইন (Secure Admin Login)**:
   - Email ও Password দিয়ে লগইন ও সেশন ট্র্যাকিং।
   - সোর্স কোডে কোনো প্লেইন টেক্সট পাসওয়ার্ড নেই; ইন্ডাস্ট্রি-স্ট্যান্ডার্ড **Web Crypto SHA-256 + Salt** এনক্রিপশন ব্যবহৃত হয়েছে।
   - অ্যাডমিন সেটিংস থেকে পাসওয়ার্ড পরিবর্তনের ব্যবস্থা।

2. **Excel Sheet-এর মতো প্রোডাক্ট টেবিল ও লাইভ হিসাব**:
   - ক্রমিক নম্বর (SL), প্রোডাক্ট নাম, প্রোডাক্ট কোড/SKU, পরিমাণ (Quantity), MRP প্রাইজ, % কমিশন/ছাড়, ডিলার প্রাইজ এবং হিসাব/মোট।
   - MRP ও % পরিবর্তনের সাথে সাথে স্বয়ংক্রিয়ভাবে ডিলার প্রাইজ ও মোট হিসাব রিয়েল-টাইমে গণনা হয়:
     $$\text{Dealer Price} = \text{MRP} - \left(\text{MRP} \times \frac{\%}{100}\right)$$
     $$\text{Row Total} = \text{Dealer Price} \times \text{Quantity}$$
   - যত খুশি প্রোডাক্ট রো যোগ (➕ Add Product) ও ডিলিট করা যায়।

3. **ইনভয়েস প্রিভিউ, সরাসরি প্রিন্ট ও অফলাইন PDF ডাউনলোড**:
   - এক ক্লিকে সরাসরি ব্রাউজার ও মোবাইল প্রিন্ট ডায়ালগ ওপেন (`window.print()`)।
   - **jsPDF** এর মাধ্যমে কোনো ইন্টারনেট বা ক্লাউড সার্ভার ছাড়াই ১০০% অফলাইনে প্রফেশনাল ভেক্টর PDF জেনারেট ও ডাউনলোড।
   - ইনভয়েসের নিচে দুই পাশে অনুমোদিত স্বাক্ষর বক্স:
     - বামে: **Company Chairman / Authorized Signature** (কোম্পানি চেয়ারম্যান / অনুমোদিত স্বাক্ষর)
     - ডানে: **Receiving Dealer Signature** (গ্রহীতা ডিলারের স্বাক্ষর)
   - A4 সাইজ এবং থার্মাল পিওএস রিসিট (Thermal Receipt) লেআউট সাপোর্ট।

4. **ডিলার ও প্রোডাক্ট ম্যানেজমেন্ট (Dealer & Product Directory)**:
   - প্রোডাক্ট যুক্ত, সম্পাদন ও ডিলিট। ইনভয়েস তৈরির সময় প্রোডাক্ট সিলেক্ট করলে স্বয়ংক্রিয়ভাবে MRP ও % বসে যায়।
   - ডিলারদের নাম, দোকান, মোবাইল নম্বর, জোন ও ঠিকানা সংরক্ষণ। প্রতিটি ডিলারের মোট ইনভয়েস ও বকেয়া ব্যালেন্স স্বয়ংক্রিয় লেজার আকারে ট্র্যাক হয়।

5. **বহুমাত্রিক অনুসন্ধান ও ফিল্টার (Advanced Search & Date Range)**:
   - তারিখ ও নির্দিষ্ট তারিখ রেঞ্জ (Date Range: যেমন 01-09-2026 হতে 30-09-2026) দিয়ে অনুসন্ধান।
   - ইনভয়েস নম্বর, ডিলারের নাম, মোবাইল নম্বর এবং পেমেন্ট স্ট্যাটাস (পেইড, আংশিক, বকেয়া) দিয়ে দ্রুত ফিল্টারিং।

6. **অ্যাডমিন ফিচার লক সিস্টেম (Feature Lock / Unlock System 🔒)**:
   - কিছু বিশেষ বা ভবিষ্যতমুখী ফিচার যেমন Advanced Reports, Cloud Sync, Multi-User Staff ইত্যাদি অ্যাডমিন সেটিংস থেকে 🔒 Locked অথবা 🔓 Unlocked করা যায়।
   - লক থাকলে ইন্টারফেসে 🔒 আইকন ও নোটিফিকেশন প্রদর্শন করে।

7. **১০০% অফলাইন ডেটাবেজ ও ব্যাকআপ/রিস্টোর (Offline First & Backup)**:
   - ইন্টারনেট সংযোগ ছাড়াই ইনভয়েস তৈরি, প্রিন্ট ও ডেটা সংরক্ষণ।
   - এক ক্লিকে সম্পূর্ণ ডেটাবেজ `.json` ফাইলে ডাউনলোড (Export) এবং যেকোনো সময় আপলোড করে পুনরুদ্ধার (Restore) করার ব্যবস্থা।
   - যেকোনো সময় ফ্রেশ টেস্ট করার জন্য ডেমো ডেটা লোড করার বোতাম।

## 📱 অ্যান্ড্রয়েড ফোন ও APK তৈরি করার গাইড (Android APK Build Guide)

এই অ্যাপটি ২ টি উপায়ে অ্যান্ড্রয়েড ফোনে ইনস্টল বা APK আকারে ব্যবহার করা যায়:

### পদ্ধতি ১: ইনস্ট্যান্ট PWA অ্যাপ (Instant PWA Install - কোনো বিল্ড ছাড়া)
1. আপনার মোবাইল ব্রাউজারে (যেমন Chrome) অ্যাপটি ওপেন করুন।
2. উপরের হেডার বারে **"Android অ্যাপ ইনস্টল"** বাটনে ট্যাপ করুন (অথবা ব্রাউজারের ৩-ডট মেনু থেকে **"Install app"** বা **"Add to Home screen"** চাপুন)।
3. অ্যাপটি আপনার অ্যান্ড্রয়েড ফোনে সাধারণ APK অ্যাপের মতো ফুলস্ক্রিনে ইনস্টল হয়ে যাবে এবং হোমস্ক্রিনে আইকন চলে আসবে। এটি অফলাইনে ইন্টারনেট ছাড়াও নির্বিঘ্নে চলবে!

---

### পদ্ধতি ২: Android Studio দিয়ে রিলিজ APK তৈরি (With Android Studio & Capacitor)

সম্পূর্ণ বিনামূল্যের ওপেন-সোর্স **Capacitor** ব্যবহার করে সহজেই APK তৈরি করা যায়:

1. আপনার প্রোজেক্ট বিল্ড করুন:
   ```bash
   npm run build
   ```

2. Capacitor CLI ইনস্টল করুন (যদি না থাকে):
   ```bash
   npm install -D @capacitor/core @capacitor/cli @capacitor/android
   ```

3. অ্যান্ড্রয়েড প্ল্যাটফর্ম যোগ করুন:
   ```bash
   npx cap add android
   npx cap sync
   ```

4. Android Studio-তে প্রজেক্ট ওপেন করুন:
   ```bash
   npx cap open android
   ```

5. Android Studio মেনু থেকে:
   - **Build > Build Bundle(s) / APK(s) > Build APK(s)** নির্বাচন করুন।
   - কয়েক মিনিটের মধ্যে আপনার অ্যান্ড্রয়েড ফোনের জন্য `app-debug.apk` বা `app-release.apk` তৈরি হয়ে যাবে!

---

### পদ্ধতি ৩: সম্পূর্ণ ফ্রি GitHub Actions CI/CD দিয়ে অটোমেটিক APK তৈরি

কম্পিউটারে Android Studio ইনস্টল না করেও GitHub-এর ফ্রি সার্ভার ব্যবহার করে APK তৈরি করতে পারেন:

1. আপনার কোড GitHub রিপোজিটরিতে পুশ করুন:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Smart Invoice Manager"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/smart-invoice-manager.git
   git push -u origin main
   ```

2. GitHub রিপোজিটরির **Actions** ট্যাবে যান।
3. `.github/workflows/build-apk.yml` এর মাধ্যমে **"Build Android APK"** স্বয়ংক্রিয়ভাবে রান হবে।
4. বিল্ড সম্পন্ন হলে **Artifacts** সেকশন থেকে সরাসরি প্রস্তুতকৃত `SmartInvoiceManager-Debug-APK.zip` ফাইলটি ডাউনলোড করে আপনার অ্যান্ড্রয়েড ফোনে ইনস্টল করে নিন!

## 💾 ব্যাকআপ ও রিস্টোর গাইড (Backup & Restore)

- **ব্যাকআপ নেওয়ার নিয়ম**:
  1. অ্যাপে লগইন করে **অ্যাডমিন সেটিংস > ব্যাকআপ** ট্যাবে যান।
  2. **"JSON ব্যাকআপ ডাউনলোড করুন"** বাটনে ক্লিক করুন।
  3. সাথে সাথে আপনার ডিভাইসে তারিখসহ `smart_invoice_backup_YYYY-MM-DD.json` ফাইল সেভ হবে।

- **রিস্টোর করার নিয়ম**:
  1. একই পেজে **"ব্যাকআপ ফাইল আপলোড করুন"** বাটনে ক্লিক করুন।
  2. আপনার পূর্বে ডাউনলোড করা `.json` ফাইলটি সিলেক্ট করুন।
  3. অ্যাপ স্বয়ংক্রিয়ভাবে ডেটাবেজ আপডেট করে পেজ রিফ্রেশ করবে।
